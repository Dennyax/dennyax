# Вертикальный разрез ΔT через Санкт-Петербург (WRF-Chem)

Скрипт `cross_section_spb.py` строит вертикальный разрез разности температуры между двумя
экспериментами WRF-Chem вдоль параллели Санкт-Петербурга. Разность осредняется за месяц отдельно
для сроков 02, 08, 14 и 20 часов. Четыре панели расположены в один столбец, шкала у них общая.

## Установка

```bash
pip install numpy pandas netCDF4 matplotlib
```

## Запуск

```bash
# пути к wrfout (по умолчанию - путь на рабочем компьютере, см. начало скрипта)
export WRF_OUT_DIR=/путь/к/WRF-Chem_out/
export WRF_SAVE_DIR=./output        # необязательно: куда сохранять рисунок (по умолчанию ./output)
python cross_section_spb.py
```

Что происходит при запуске:

1. Если в `data/` есть файл `section_spb_<эксперимент>_minus_<контроль>.npz` с теми же параметрами,
   то `wrfout` не читаются, а рисунок строится из `.npz`.
2. Иначе скрипт читает `wrfout`, считает средние за месяц, сохраняет их в `data/*.npz` и строит рисунок.
   Параметры разреза запоминаются в `.npz`: если вы их поменяете, средние пересчитаются из `wrfout`.
   Если `wrfout` недоступны, скрипт завершится с ошибкой.

Принудительный пересчёт: `use_cache = False` в начале скрипта.

## Настройки (начало `cross_section_spb.py`)

| Параметр | Что задаёт |
|---|---|
| `file_exp`, `file_ctrl` | какие файлы вычитаем: ΔT = эксперимент − контроль |
| `var_name` | `'T'` - стандартная переменная WRF, температура считается из `T`, `P`, `PB`; любое другое имя читается как есть |
| `target_lat`, `target_lon` | широта разреза и долгота города (пунктирная линия) |
| `lon_min`, `lon_max` | границы разреза по долготе |
| `z_top` | верх разреза, м над поверхностью |
| `hours_sel`, `utc_shift` | сроки осреднения и сдвиг от UTC (`3` - местное время) |

## Что хранится в репозитории

- Скрипты (`*.py`) и осреднённые разрезы `data/*.npz`: они небольшие (десятки КБ).
- Исходные `wrfout_*.nc` и рисунки (`output/`) в репозиторий не добавляются (см. `.gitignore`).
  GitHub не принимает файлы больше 100 МБ. Исходные данные храните на диске или в облаке.

Как добавить результаты после запуска на своём компьютере:

```bash
git add cross_section_spb.py data/*.npz
git commit -m "Update cross-section results"
git push
```
